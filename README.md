# FrameEyeCameraFeed-Installer
Automatic installer and setup for [FrameEyeCameraFeed](https://github.com/Curtis-VL/FrameEyeCameraFeed/)!

This installer also guides you through setting up EyeTrackVR and VRCFaceTracking to be used in VRChat.

https://github.com/user-attachments/assets/886a8193-d35e-411f-8950-9c35102e17fd

## How to use

1. Download the latest release here: [Latest Release](https://github.com/Curtis-VL/FrameEyeCameraFeed/releases)
2. Extract all files to a folder.
3. Run 'FrameEyeCameraFeed-Installer.exe'
